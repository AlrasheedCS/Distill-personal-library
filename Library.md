# Source library

Keep the source close to the thinking it supports.

| Source | Where it goes | Start with |
| --- | --- | --- |
| Chat | `sources/chats/chatgpt/` or `sources/chats/claude/` | Title + original URL |
| Search (AI) | `sources/searches/` | Original text in `raw/` + one search note |
| Paper or report | `sources/papers/` | Link or DOI + why you saved it ([[system/templates/Paper|Paper template]]) |
| Find from X or the web | `sources/finds/` | URL + author + useful point; for an X thread, the main posts quoted |

Use [[system/templates/Find|Find]] with the core Templates command. Move the new note to its source folder. Store local PDFs and images in `system/attachments/` and link them from the source note.

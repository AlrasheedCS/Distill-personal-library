# chatgpt

Saved ChatGPT chats, one note each.

> [!tip] How to use this folder
> - **How things get in:** Say "save this chat" to an AI that can reach the vault (see [[system/prompts/Save this chat]]), or use the ChatGPT export and tick the chats to import ([[system/Migration checklist]]).
> - **Template:** [[system/templates/Chat capture]]
> - **Example:** [[system/template examples/Chat (example)]]
> - **Then:** Highlight lines you want to keep with ==text== and copy the best into *My highlights*. Set `projects` to link it to a project.

# keepers

Your best-of shelf: the final answer after the searching and chatting, in any area. Hub: [[keepers/Keepers]].

> [!tip] How to use this folder
> - **How things get in:** say "keep this" to an AI about a specific finding, or write one yourself. AIs only *propose* keepers, as drafts in `agent/outputs/keeper-candidates/`.
> - **Template:** [[system/templates/Keeper]]
> - **Example:** [[system/template examples/Keeper (example)]]
> - **Then:** set `area` and `kind`; for things that change (places, prices, tools) set a `recheck` date. Only you edit, move or delete keepers; the commit script blocks deletions unless you confirm.

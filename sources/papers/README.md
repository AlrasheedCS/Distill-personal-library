# papers

Research papers, reports and preprints you've read or want to read, one note each.

> [!tip] How to use this folder
> - **Add one:** create a note from [[system/templates/Paper|the Paper template]], paste the link or DOI, and fill in *Why I saved it*. Or capture the link to [[inbox/to sort|To sort]] and say "sort my inbox".
> - **Keep the PDF** in `system/attachments/` and link it from the note.
> - **Ask an AI** to fill in the summary: it writes in the `[!ai]` box only, labels every line, and never touches *My highlights*.
> - **Link it** to a project with the `projects` property, and to the chats or searches that led you to it.
> - Example: [[system/template examples/Paper (example)]].

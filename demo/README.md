# Demo vault

Want to see Distill full before you start your own? **Distill-demo.zip** is the same vault filled with about 30 fictional notes on working with AI: saved chats, coding sessions, a search, a paper, finds, two projects, an AI topic map, keepers, how-tos and drafts waiting for review.

1. Unzip it anywhere (outside your own vault).
2. In Obsidian: **Open folder as vault** → `Distill demo`.
3. **Settings → Community plugins → Turn on community plugins**, then install the plugins listed in the main README (*Look and plugins*). Their settings are already in the demo.
4. It opens on **Home**, with tabs for a saved chat, the topic map, Keepers, Chats and a project.

All people, chats, posts and papers in the demo are made up. Delete the demo whenever you like; your own vault is the main folder of this repository.

# Searches

**Not chats.** Outputs from searches you ran with AI tools (Grok or ChatGPT searching X and the web, deep-research reports) that you saved somewhere else, like Apple Notes. They have no conversation link or full transcript, only the answers you kept.

Each search note: About · Main insight · End result · Key insights · one section per output. The original text stays word for word in `raw/`.

```query
path:"sources/searches" -path:"sources/searches/raw" -file:"Searches"
```

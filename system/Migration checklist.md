# Import checklist

For bringing in a backlog from an export. Only ticked chats are imported.

## ChatGPT

- [ ] Request: ChatGPT → Settings → Data controls → Export data.
- [ ] Unzip the download outside the vault, into a folder the AI can reach.
- [ ] Keep images, attachments and raw export data in that external archive. Import notes and text transcripts only unless you explicitly want a particular file.
- [ ] Ask the AI to import it. It writes `agent/outputs/import-candidates-<date>.md`.
- [ ] Tick the chats to keep (e.g. pinned and project chats).
- [ ] Say "import the ticked chats". Batches of 10–20 keep usage down.
- [ ] Check them in [[ChatGPT home]].

## Claude

- [ ] Request: Claude → Settings → Privacy → Export data.
- [ ] Same steps as above. Claude Code sessions aren't in the export; they're saved one by one with "save this to my vault" or listed through the browser.
- [ ] Check them in [[Claude home]].

## Afterwards

- [ ] Review drafts in **Waiting for you** on [[Home]].
- [ ] If search stops finding things, see qmd in [[system/Improve later]].

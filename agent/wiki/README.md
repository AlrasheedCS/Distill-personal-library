# wiki

AI-written pages on patterns across several chats.

> [!tip] How to use this folder
> - **How things get in:** AIs create them when 3+ chats cover the same thing.
> - **Then:** Every line is labelled `[source]`, `[inferred]`, `[mine]` or `[verified]` and links the chat behind it. Treat them as leads, not facts.

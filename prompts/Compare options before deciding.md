# Compare options before deciding

> [!info] Starter prompt shipped with Distill. Edit it, rename it or delete it.

## When to use it

Weigh a few options side by side.

## Prompt

```text
Help me decide: {decision}.
Options: {options}. What matters to me: {what matters to me}.
Make a table: each option against each criterion, with a short reason per cell.
Then list deal-breakers, what you'd need to know to be sure, and which you'd pick and why.
```

## Variables

- `{options}`
- `{what matters to me}`

# projects

One note per project you research or build with AI.

> [!tip] How to use this folder
> - **How things get in:** Create a note from the template; set the `projects` property on chats, finds and papers to link them.
> - **Template:** [[system/templates/Project]]
> - **Example:** [[system/template examples/Project (example)]]
> - **Then:** Chats and finds list themselves on the project page. AI ideas wait in an `[!ai]` box until you keep them.

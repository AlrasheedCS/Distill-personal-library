# Projects

Use local project notes for outcomes and next actions. Keep source files in sources, linked from here.

**Linking chats to a project:** set the chat's `projects` property to the project note, e.g. `projects: ['[[projects/Improve this vault]]']`. The project note lists those chats by itself (its "Chats in this project" table). A chat can belong to several projects. This is separate from `chatgpt_project`, which is the ChatGPT or Claude app project the chat lived in.

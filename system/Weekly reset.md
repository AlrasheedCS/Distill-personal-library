# A ten-minute reset

- [ ] **To sort:** say "sort my inbox" to an AI; tick what it proposes. ([[inbox/to sort]])
- [ ] **Waiting for you** on [[Home]]: keep, edit or skip a draft or two.
- [ ] **Mark a few chats** you'll want again: `priority: high` or `review: to review` (only marked chats get rewritten).
- [ ] **Projects:** glance at the AI-proposed Ideas in your [[projects/Projects|project notes]]; move the ones you accept out of the `[!ai]` box.
- [ ] **How-tos to test**: tick `tested` on any you've actually done.
- [ ] **Random revisit:** command palette → *Random note: Open random note*. Fix a link, add a `[!mine]` comment, or leave it.

Leave the rest alone. The vault should save attention, not demand it.
